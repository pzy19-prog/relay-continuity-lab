| Gate | Evidence required |
|---|---|
| G0 Name / competitor validation | hands-on competitor records, naming checks |
| G1 Durable task contract | typed schema, restart state rehydration |
| G2 One safe local E2E | task -> handoff -> executor -> independent verification -> receipt -> decision -> resume |
