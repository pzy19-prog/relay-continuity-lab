# Devlog 0003：让 Relay 不再依赖复制 Skill 文本

状态：**已实装且通过隔离容器中的自动测试；等待 WSL 真实 Cursor Agent 发现和调用证据。**

G2 已证实：人手传递任务包，真实本地 Agent 修复合成代码，Relay 再用 Git 证据和独立测试验证、经人工批准后恢复任务。它没证明 Skill 安装和 Agent 发现。

G3 这次增加可安装项目级 Skill：不默认污染用户全局配置，先安装到**全新合成仓库**、作为 Git 基线提交，再通过安装副本的 CLI 创建任务和交接。Skill 所依赖的最小 CLI/Core 随安装复制，消除原来依赖源码项目绝对路径的脆弱性。

安装器具备 `--status` / `--uninstall`，不覆盖来源不明的同名目录，也不静默删除用户修改。独立测试覆盖安装/卸载、冲突、不干扰 Git fixture、安装副本的任务操作和完整**模拟**验证流程。

已知边界：复制的 CLI 不会自动与 Chat、Work、Codex 会话通信；声明 actor 字段不等于认证执行者；独立测试对恶意仓库不是执行沙箱；项目级 Skill 是否在真实 Cursor WSL 中发现和调用，必须看真实执行日志。此前测试中也出现过嵌套 Node 测试上下文继承导致的伪成功，新增测试都清理该环境变量，并检查预期初始测试确实失败。

后续将公开脱敏的真实调用和故障记录。若真实环境无法发现 Skill，先修复安装入口，而不是扩展多模型适配器。
